```
1. Calculate the radial pixel intensity profile for the bezel ring

3. Beyond the horizon dip radius, mathematically curve the intensity back towards the bright channel mean

```

### 2.6 Technical Approach

* **Module:** `src/boostgauge/skins/stingray.py`
* **Pattern:** Procedural drawing (PIL ImageDraw)
* **Key Decisions:** The visual profile of the bezel ring will be modified using a procedural piecewise math function to ensure the reflection is back above the required brightness within the specified distance from the dark dip. This fulfills S10r without violating the numerical procedural render contract or breaking S10g.
