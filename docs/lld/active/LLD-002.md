### 2.5 Logic Flow (Pseudocode)

```
1. ON STARTUP:
   - Read `telltale_windows` from config.
   - Construct TelltaleGroup with 4 instances (short, medium, long, None).
2. ON COLLECTOR TICK:
   - TelltaleGroup.update(timestamp, value) iterates all 4 instances.
3. ON RENDER TICK:
   - peaks = TelltaleGroup.current_peaks()
   - boostgauge.skins.stingray.render(value, peaks, size)
4. ON MENU HOVER/CLICK:
   - Display labels from TelltaleGroup.get_menu_labels() or get_tooltip_text()
   - Dispatch reset selection to TelltaleGroup.reset_target(target)
```

## 3. Requirements

1. The application constructs four `Telltale` instances: three with durations read from `telltale_windows.short`, `medium`, and `long`, and one with window `None` for all-time.
2. Every collector sample reaches all four instances identically via `Telltale.update(timestamp, value)`.
3. Every refresh passes all four `current_peak()` values to #332's renderer as a four-slot sequence, passing `None` values through unmodified.
4. Reset actions dispatch to their specific target instance: short, medium, long, all-time, or all four simultaneously.
5. Menu entry labels are dynamically formatted from the configured durations (e.g., 'Reset 90s', 'Reset 15m') via a pure formatter.
6. The hover tooltip text dynamically formats each window label bound to its aesthetic color name (cyan, orange, magenta, coral red) via a pure function.
7. Render-tier tests verify the composed image through #332's real renderer using self-generated baselines as regression pins, and detect needle presence/absence by classifying pixels against the aesthetic document's palette rows.

## 4. Alternatives Considered

| Option | Pros | Cons | Decision |
|--------|------|------|----------|
| Mix string formatting into `tkinter` bound events | Simpler codebase | Violates Option C test strategy; untestable | **Rejected** |
| Pure `TelltaleGroup` mapping class | 100% unit testable, centralizes all W and RS criteria | Slight boilerplate | **Selected** |

**Rationale:** The Option C test strategy completely bans `tkinter` from test runs. Placing formatting and dispatch logic into a pure class is the only way to satisfy the exhaustive branching requirements of U1 and RS6 without invoking a GUI runtime.
