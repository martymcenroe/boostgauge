boostgauge

Real-time system monitor styled like a racing tachometer.

Lightweight, always-on-top desktop gauge that tracks ConPTY allocations, memory, processes, and handles — collapsing them into a single composite needle with peak-hold (telltale) marks at 1m, 10m, 1h, and all-time windows.

Built for developers running multiple concurrent AI coding sessions who need real-time visibility into invisible resource pressure.

Pre-release Version 0.0.0 currently reserves the name on PyPI. The first real release ships during the AssemblyZero speedrun launch — built from zero to PyPI on stream.
