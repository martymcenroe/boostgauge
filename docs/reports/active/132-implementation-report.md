## Summary

Retroactive Poetry/pytest bootstrap from audit §2.1–§2.2. Before this commit, the repo had no `pyproject.toml`, no `poetry.lock`, no installed test runner — the AssemblyZero implementation workflow would crash within ~90s of any run when its red-phase `pytest` invocation hit `FileNotFoundError`.

## Changes

### `pyproject.toml`

Initialized via `poetry init --no-interaction` with:

- `name = "boostgauge"`, `version = "0.1.0"`
- `description = "Real-time system monitor styled like a racing tachometer"`
- `requires-python = "^3.10"`
- `license = "PolyForm-Noncommercial-1.0.0"`
- Poetry 2.x emitted PEP 621 layout (`[project]` table), modern convention.

Runtime deps added via `poetry add psutil pillow pystray`:

| Package | Constraint resolved by Poetry |
|---|---|
| psutil  | `>=7.2.2,<8.0.0`  |
| pillow  | `>=12.2.0,<13.0.0` |
| pystray | `>=0.19.5,<0.20.0` |

Dev deps added via `poetry add --group dev pytest pytest-cov`:

| Package | Constraint |
|---|---|
| pytest     | `>=9.0.3,<10.0.0` |
| pytest-cov | `>=7.1.0,<8.0.0`  |

Appended `[tool.pytest.ini_options]` block (testpaths, file/class/function patterns, `-ra --strict-markers`) so discovery is deterministic across the 12-subdirectory `tests/` scaffold from `new_repo_setup.py`.

### `poetry.lock`

Generated by Poetry. Locks the full transitive dependency graph (12 packages total — 4 runtime + six + 7 dev/coverage transitives).

### `tests/conftest.py`

Adds `src/` to `sys.path` so test files can `import boostgauge.*` once any source lands.
